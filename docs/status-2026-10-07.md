and validating fresh installation media. The owner
has now requested physical acceptance; a fresh live candidate11 software preflight

## NVIDIA display and library fixes

Steam animations corrupted PC1's direct gamescope display while compositor
screenshots remained clean. Source now selects accelerated Xorg on connected
NVIDIA displays, includes matching Xorg/GLX modules from the pinned sidecar and
selects the fastest advertised progressive mode at the preferred resolution.
The owner confirmed Steam was smooth and stable at 3440×1440 / 174.96 Hz. The
image-scoped bench hotfix and actual session restart passed; a replacement image
build and full machine reboot remain untested for these fixes. See
[ADR 0013](adr/0013-nvidia-xorg-display.md) and the
[display investigation](steam-display-corruption-20261007.md).

The application scanner merges desktop Steam shortcuts with installed manifest
records by numeric App ID and launches the native Steam card through the shared
Big Picture helper. The display investigation records 61 focused controller,
parser and integration checks passing, plus the real Linux uinput fixture.

Current source validation in the configured disposable Fedora environment runs
250 backend tests: 248 pass and two optional checks skip. Controller shell
regressions, session/acceptance shell syntax and component-pin verification pass.
Controller and shell source copies are committed in their component repositories
and the integration pins match those exact local commits. This validation does
not establish replacement-image or additional physical acceptance.
